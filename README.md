## Instrucciones de uso:

## Construir y ejecutar:
   ## docker-compose up --build -d

## Verificar servicios:
  ## docker-compose ps

## Ver logs:
 ##  docker-compose logs web
 ## docker-compose logs db
   
## Acceder a la aplicación:
   ## Web: http://localhost:8082
   ## MySQL: localhost:3307

## Detener servicios:
   ## docker-compose down
